# AB180(에어브릿지) GTM 리드의 Claude Code 기반 세일즈 자동화 — 업계 AI 에이전트 실사용 리서치

Date: 2026-09-20
Scope: 경쟁사(가전/스마트홈) 리서치가 아니라 **업계 AI 에이전트 실사용 사례** 트랙(ai-agent-usage-research 스킬 범위). AB180은 모바일 앱 분석 솔루션(MMP) 회사로 LG전자의 직접 경쟁사가 아님 — "AI 에이전트를 세일즈/GTM 실무에 어떻게 적용하는지"의 참고 사례로 수집.

**출처 성격 주의**: 이 글의 원문(maily.so/josh/posts/x1zg58l9oqg)은 이 세션의 네트워크 정책상 직접 접근이 차단되어(EGRESS_BLOCKED) 있고, 아래 내용은 사용자가 채팅에 직접 붙여넣은 원문 텍스트를 그대로 정리한 것이다. 내가 독립적으로 원문·2차 출처를 대조 검증하지 않았으므로, **verifier 에이전트의 검증 전 단계**로 취급해야 한다.

## Key findings

- **AB180(에어브릿지)의 GTM 리드 최현종은 2026년 2월 Claude Code를 처음 사용, 한 달 만에 15개 시스템을 구축했다.** (source: 최현종 인터뷰, maily.so/josh, 2026.08.21 게시, 조회 4.92K)
- **"AI가 영업을 대체한다"가 아니라 "영업의 본질이 선명해져 사람이 해야 할 일이 늘었다"는 것이 핵심 주장.** AI가 대체하지 못하는 영역으로 (1) 계약에 대한 신뢰·책임의 귀속, (2) 상대만 갖고 있는 암묵지 정보, (3) 녹음되지 않는 대화 맥락을 꼽았다. (source: 동 인터뷰)
- **리드 퀄리피케이션 자동화(1호 프로젝트)**: 이메일 도메인 유효성, 전화번호 존재, 앱 등록 여부, 웹사이트 스크래핑 등을 규칙화해 리드 스코어링. 느슨한 기준 시 약 60% 통과, 엄격한 기준 시 20~30%대로 통과율이 낮아짐. Zapier→Mixmax로 연동해 퀄리파이드 리드에 자동 이메일 시퀀스 발송. (source: 동 인터뷰)
- **스캠/스팸 패턴 탐지에 별도로 공을 들임** — 회사명에 "테스트", "코리아" 같은 일반명사나 유명인 이름(일론 머스크, 스파이더맨 등)을 넣는 패턴을 걸러내는 로직을 고도화. 해외 리드일수록 가짜 SEO 업체·성인사이트발 스팸 유입이 많다고 언급. (source: 동 인터뷰)
- **피드백 루프**: 실제 클로징된 고객 유형을 Claude Code에 지속적으로 학습시켜, 사람이 설계하지 않은 스코어링 규칙을 시스템이 스스로 제안하기 시작했다고 함(정량적 성과 수치는 제공되지 않음 — 검증 필요). (source: 동 인터뷰)
- **이메일 팔로업 추적/분류 AI**: 발송한 이메일에 답장이 필요한데 안 왔는지 감지, 답장 반응(관심 있음/없음/보류)을 자동 로깅. (source: 동 인터뷰)
- **"마그넷 플레이" 툴 — 구독앱 리뷰 분석 리포트**: 잠재고객의 앱스토어/플레이스토어 리뷰를 수집해 이탈 신호를 자동 추출. 예시로 든 "듀오링고 리뷰 1,000개 분석 → 118개 이탈 시그널 탐지, iOS/안드로이드 각 8개 패턴 도출"은 **실제 듀오링고 고객 사례가 아니라 데모/예시 목적으로 만든 것으로 보임 — 문맥상 불명확, 확인 필요**. 퀄리파이드 리드에는 개인화 리포트를, 비퀄리파이드 대상에는 GitHub 공개 링크(Claude Code skill)로 배포. (source: 동 인터뷰)
- **"시그널 기반 아웃바운드(signal-based outbound)"는 이미 죽었다고 주장** — "최근 이런 콘텐츠 보셨죠" 식 개인화 멘트가 업계에 만연해지며 오히려 스팸 신호로 인식된다는 논지. 대신 실제로 써볼 수 있는 도구/리포트를 제공하고 사용 여부를 트래킹해 관계를 구축하는 방식이 더 효과적이라고 주장(정량적 전환율 수치는 미제공). (source: 동 인터뷰)
- **인터뷰 아웃리치 트래커**: 최근 제품을 활발히 사용한 유저를 자동으로 찾아 리스트업, 첫 줄만 개인화하고 나머지는 템플릿으로 발송(토큰 비용·작업량 절감 목적). (source: 동 인터뷰)
- **사내 "세일즈 OS"**: 미팅 기록 + 세일즈포스 데이터를 결합해 내러티브를 선택하면 팔로업 메시지/첨부파일이 자동 생성됨. 사내 "지식 에이전트" 툴과 연동. (source: 동 인터뷰)
- **"세일즈 위키"를 사람이 아니라 에이전트가 읽도록 설계** — 협상 규칙 등을 담은 사내 SSOT(Single Source of Truth) 문서를 Claude Code가 작업 전에 항상 참조하도록 구성. "담당자가 미처 생각 못한 협상 방어 논리를 에이전트가 제안"한 사례를 언급(구체적 사례는 미제공). (source: 동 인터뷰)
- **제안서를 정적 PDF가 아니라 인터랙티브 웹으로 제작** — 고객사 브랜드 컬러 반영, 라이브 데모 포함, 사내 블로그 콘텐츠를 자동으로 최신화해 반영. (source: 동 인터뷰)
- **사내 AI 도입 확산 방식**: 2026년 설날(음력 1월, 대략 2월 중) 직후 자발적으로 "AX 교육"/Claude Code 캠프 시작 → 4일 교육 + 1주일 프로젝트 발표 사이클을 여러 차례 운영 → 현재 약 45~50명 교육 이수. **"AI를 잘 쓴 사람이 승진·보상받게 하는 것"을 안착의 핵심 원칙으로 제시** — 발표 성과에 따라 구독 계정 유지/해지를 결정하는 인센티브 설계. 실패 요인으로 "Claude Code를 자동화 도구로만 오인하는 것"과 "공용 스킬 제작이 개인 스킬보다 훨씬 어렵다(사실상 제품 개발 수준)"는 점을 꼽음. (source: 동 인터뷰)
- **"생각의 증강 도구"라는 프레이밍** — 단순 자동화가 아니라 사고를 명료화하는 도구로 강조. "Clarify"라는 스킬/플러그인으로 모호한 생각을 질문을 통해 명시지로 전환한다고 언급. CLAUDE.md에 "모르는 게 있으면 되물어보라"는 지침을 넣을 것을 권장. (source: 동 인터뷰)
- **Anthropic 자체 사례 인용(2차 출처, 미검증)**: "SaaStr 컨퍼런스에서 Anthropic 세일즈 리더가 엔터프라이즈 세일즈의 셀프서브·AI 대체 실험을 발표했다"는 내용을 언급 — **날짜·발표자명·구체 내용이 특정되지 않아 별도 확인 필요**.

## 트랙 분류 노트

이 리서치는 `competitor-research`가 통상 다루는 "가전사 UX/AI 경쟁" 트랙이 아니라, `ai-agent-usage-research` 스킬이 정의하는 **"실무자의 AI 에이전트 실사용 패턴"** 트랙(세일즈/GTM 직군)에 해당한다. LG전자 자사 비교에 바로 쓰기보다는, "AI 에이전트를 사내에 어떻게 확산·정착시켰는가"(인센티브 설계, 교육 커리큘럼, 에이전트 전용 사내 위키 설계) 참고 사례로 `report-writer`가 활용하는 것이 적합해 보인다.

## Open questions / gaps

- 듀오링고 리뷰 분석 사례가 실제 고객 데이터인지 데모용 예시인지 불명확 — 원문에서 명확히 구분되지 않음.
- 정량적 성과 지표(전환율, 미팅 성사율, 매출 기여도 등)가 거의 제공되지 않음 — 전반적으로 정성적 주장 위주.
- Anthropic SaaStr 발표 관련 2차 인용은 날짜·발표자·1차 출처가 없어 별도 검증 필요.
- 원문 게시물 자체(maily.so)에 직접 접근하지 못해, 사용자가 붙여넣은 텍스트 외의 이미지·차트 등 시각 자료는 반영되지 않았음.
- LG전자 자사 사례와의 직접적 연결점(예: LG전자 B2B 세일즈 조직이 유사한 AI 도구를 쓰는지)은 별도 조사 필요.
