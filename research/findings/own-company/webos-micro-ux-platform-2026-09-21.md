## Key findings

- **LG전자 UX연구소는 UX 경쟁력 강화를 위해 webOS Micro OS가 적용되는 대화면 가전 제품의 UX
  플랫폼을 구축했다.** (source: 사용자 제공(내부 정보), 2026-09-21)
- **webOS Micro 대화면 가전의 플랫폼 UX 구축을 위해 General Guide를 제작했다.**
  (source: 사용자 제공(내부 정보), 2026-09-21)
- **35종의 공통 컴포넌트를 설계했다.** (source: 사용자 제공(내부 정보), 2026-09-21)
- **10종의 System Feature 시나리오를 설계했다.** (source: 사용자 제공(내부 정보), 2026-09-21)
- **이를 통해 다양한 제품 화면 환경에 대응하는 유연한 GUI 설계를 확보했다.**
  (source: 사용자 제공(내부 정보), 2026-09-21)
- **결과적으로 제품 간 UX 일관성과 개발 효율을 확보했다.** (source: 사용자 제공(내부 정보),
  2026-09-21)

## 트랙별 노트

### 외부(제품·시장)
- (해당 없음 — 이 항목은 내부 플랫폼/디자인 시스템 구축 활동에 관한 것이며, 외부에 공개된 제품·
  마케팅 발표가 아니다.)
- **(참고용 외부 맥락, 사용자 제공 정보 아님)** webOS는 2014년부터 LG TV 전 라인업에 탑재되어 온
  LG의 스마트 플랫폼이며, 냉장고(InstaView 등)·프로젝터·기타 IoT 제품에도 확장 적용되어 온 이력이
  외부 자료에서 확인된다. 또한 webOS는 ThinQ와 연동되는 "Home Hub" 기능을 통해 TV 화면을 다른
  LG 가전을 제어하는 허브로 활용하는 방향으로 발전해 왔다(2026년형 webOS 26에도 Home Hub 기능
  고도화가 포함됨). 다만 "webOS Micro"라는 명칭이 대화면 가전(예: 냉장고 도어 디스플레이 등)에
  적용되는 별도의 경량 OS 변형을 가리키는 공식 제품/기술 용어로 외부에 공개되어 있는지는 이번
  서치로 확인하지 못했다 — 존재 여부, 정식 명칭, 공식 위치(webOS 제품군 내 서브셋인지 별도
  브랜드인지)를 외부 자료로 검증할 수 없었다는 점을 명시한다.
  (source: [What is webOS? | LG USA](https://www.lg.com/us/webos/about),
  [LG's Smart InstaView webOS Fridge Has Alexa And Transparent Touchscreen — SlashGear](https://www.slashgear.com/lgs-smart-instaview-webos-fridge-has-alexa-and-transparent-touchscreen-04470086/),
  [webOS 26 begins rolling out to older LG TVs — FlatpanelsHD](https://www.flatpanelshd.com/news.php?subaction=showfull&id=1787298592))

### 내부(조직·R&D)
- 이번 활동은 "General Guide 제작 → 공통 컴포넌트 35종 설계 → System Feature 시나리오 10종
  설계 → 다양한 화면 환경에 대응하는 유연한 GUI 설계 확보"라는 구조로 이해된다. 즉 개별 제품
  UX가 아니라, 여러 대화면 가전 제품이 공유하는 디자인 시스템/플랫폼 계층을 구축한 것으로
  보인다(사용자 제공 정보에 근거한 해석).
- **(에이전트 자체 추론, 사실 아님)** `research/reports/2027-ux-agenda-2026-09-20.md`의 02번
  테마("AI UX 표면이 허브 하나에서 가전 전체로 퍼진다")와 직접 맞닿아 있어 보인다. 해당 테마는
  AI UX가 TV 등 단일 허브에서 냉장고·오븐·세탁기 등 개별 대화면 가전으로 확산되는 경쟁 구도를
  다루는데, 이번 webOS Micro 플랫폼(공통 컴포넌트 35종 + System Feature 시나리오 10종)은 LG전자가
  바로 그 "여러 대화면 가전에 걸친 UX 확산"을 감당하기 위해 자체적으로 구축한 인프라/디자인
  시스템 답변으로 읽을 수 있다. 다만 이는 에이전트의 추정이며, 사용자가 이 프로젝트를 해당 테마와
  직접 연결해 확인해 준 사실은 아니다.
- **(에이전트 자체 추론, 사실 아님)** 이 프로젝트는 사용자가 최근 제공한 세 번째 UX연구소
  2026년 프로젝트다 — ① `ux-governance-audit-2026-09-21.md`(전사 UX 거버넌스·Audit, B2C→B2B
  확장 및 AI Agent 아이덴티티 거버닝), ② `ux-competitiveness-assessment-2026-09-21.md`(경쟁력
  진단 평가 체계 확립 및 개선 40건), ③ 이번 webOS Micro 대화면 가전 UX 플랫폼 구축. 세 프로젝트
  모두 "UX 경쟁력 강화"라는 공통 목적을 표방하고 있어, 조직적으로 상위의 단일 이니셔티브 아래
  묶여 있을 가능성이 있어 보이나, 세 활동이 실제로 하나의 프로그램인지 각기 독립된 과제인지는
  사용자가 확인해 주지 않아 알 수 없다. 성격상으로는 ①이 상시 품질 관리(거버넌스), ②가 진단·
  방향수립(어세스먼트), ③이 플랫폼/인프라 구축(디자인 시스템)으로, 서로 다른 층위의 활동으로
  보인다는 점만 추정 가능하다.

## Open questions / gaps

- **적용 제품 범위** — webOS Micro OS가 구체적으로 어떤 제품/제품 라인(예: 냉장고 도어 디스플레이,
  오븐, 세탁기 등)에 적용되는지 명시되지 않았다.
- **시기** — 2026년 중 정확히 언제(상반기/하반기, 특정 분기) 진행/완료되었는지 불명확.
- **System Feature 시나리오의 실제 내용** — 10종의 System Feature 시나리오가 구체적으로 어떤
  기능(예: 음성 UX, 알림, 온보딩, 펌웨어 업데이트 등)을 다루는지 항목별 목록이 제공되지 않았다.
- **35종 컴포넌트와 10종 시나리오의 구조적 관계** — 공통 컴포넌트(35종)와 System Feature
  시나리오(10종)가 서로 어떻게 매핑/연계되는지(예: 각 시나리오가 특정 컴포넌트 조합으로
  구현되는 구조인지) 불명확.
- **General Guide의 배포 대상** — 이 가이드가 LG전자 내부 개발/디자인 조직만을 대상으로 하는지,
  아니면 외부 파트너·라이선시(예: OEM/ODM 협력사)에게도 제공되는 문서인지 불명확.
- **"webOS Micro" 명칭의 공식성** — 외부 공개 자료(LG 뉴스룸, 제품 페이지 등)에서 "webOS Micro"를
  독립된 공식 명칭으로 확인하지 못했다. 사내에서만 쓰이는 프로젝트/플랫폼 명칭인지, 아니면 외부
  미공개 예정인 정식 제품 브랜드인지 불명확하다.
- **`ux-governance-audit-2026-09-21.md`, `ux-competitiveness-assessment-2026-09-21.md`와의
  조직적 관계** — 세 프로젝트가 하나의 상위 이니셔티브인지, UX연구소 내 서로 다른 팀이 독립적으로
  진행한 별개 과제인지 사용자 확인이 필요하다.
- 외부에 공개된 정보가 아니므로, 2027 사업계획 외부 공유 자료에 이 내용을 포함할 경우 사내 보안/
  공개 범위 정책을 먼저 확인해야 한다.
