## Key findings

- **LG전자 UX연구소는 "미래 준비 디자인(winning design) 선제안" 과제에서, "UX 경쟁력 강화" 측면으로
  "AI Agent 전사 가이드 정립 및 제품별 적용을 통한 경쟁력 확보"를 진행했다.** (source: 사용자 제공
  (내부 정보), 2026-09-21)
- **글로벌 경쟁사 벤치마킹을 통해 AI Agent 기회 영역을 발굴했다.** (source: 사용자 제공(내부 정보),
  2026-09-21)
- **신규 경험 아이디에이션을 진행했다.** (source: 사용자 제공(내부 정보), 2026-09-21)
- **이를 기반으로 UX/GUI 가이드 1.0을 배포했다.** — 이 단계는 완료형으로 서술됨. (source: 사용자
  제공(내부 정보), 2026-09-21)
- **제품별 적용 협의를 진행했다.** — 이 단계는 사용자 표현상 "진행"으로, 완료가 아니라 협의가
  이루어지는 중/이루어진 것으로 읽힌다(아래 "진행 상태 분류" 참조). (source: 사용자 제공(내부 정보),
  2026-09-21)
- **주요 인터랙션 개선을 추진했다.** — 이 단계 역시 사용자 표현상 "추진"으로, 완료 확정형이 아니다
  (아래 "진행 상태 분류" 참조). (source: 사용자 제공(내부 정보), 2026-09-21)

## 진행 상태 분류 — 단계별로 완료도가 다르다 (뭉뚱그리지 말 것)

사용자가 제공한 원문 표현을 보면 이 프로젝트의 다섯 단계는 완료도가 균일하지 않다. `09`
(P2D 플러그인) 항목에서 "완료/제안/PoC 개발 중"의 3분류를 도입했던 것과 같은 원칙으로, 이번
항목도 단계별로 나누어 기록한다.

| 단계 | 사용자 원문 표현 | 완료도 해석 |
|---|---|---|
| ① 경쟁사 벤치마킹 → AI Agent 기회 영역 발굴 | "발굴" | 완료형으로 읽힘 |
| ② 신규 경험 아이디에이션 | "진행" | 활동이 이루어졌다는 의미로, 완료형에 가까움(다만 아이디에이션은 본질적으로 산출물이 "확정"이 아니라 "안" 수준일 수 있음) |
| ③ UX/GUI 가이드 1.0 배포 | "**배포**" | **가장 명확한 완료형** — 버전 넘버(1.0)까지 붙어 있어 실제 문서가 나와 배포된 것으로 보임 |
| ④ 제품별 적용 협의 | "**협의를 진행**" | **미완료/진행 중** — "적용 협의"이지 "적용 완료"가 아님. 어떤 제품에 실제로 반영됐는지는 별도 확인 필요 |
| ⑤ 주요 인터랙션 개선 | "**개선을 추진**" | **미완료/진행 중** — "추진"은 착수·진행 단계를 가리키는 표현으로, 개선이 실제 제품에 반영 완료됐다고 단정할 수 없음 |

**결론(에이전트 판단, 근거는 사용자 제공 원문): 이 프로젝트는 "가이드 제작"까지는 완료됐으나,
"가이드의 제품 반영(적용)"은 아직 협의/추진 단계로, 가이드 배포와 실제 제품 적용 사이에 시차가
있는 것으로 보인다.** `report-writer`/`verifier`는 "AI Agent 가이드를 만들었다"와 "AI Agent
가이드가 제품에 반영됐다"를 같은 완료도로 서술하지 말 것.

- **(참고용 외부 맥락, 사용자 제공 정보 아님)** 업계 전반에서 "AI 에이전트 UX/디자인 가이드라인"은
  2026년 기준 빠르게 표준화되는 영역으로 소개된다. Agent UX(에이전트를 위한 UI 설계)는 자율
  소프트웨어가 사용자를 대신해 행동을 취하는 인터페이스를 설계하는 실천으로, 전통적 UI가 다루지
  않던 투명성(에이전트가 무엇을 하고 있는지 보여주기), 상태 전달, 오버라이드(사용자 개입) 제어,
  오류 복구 같은 패턴이 필요하다고 소개된다. Gartner는 2026년 말까지 전체 엔터프라이즈 애플리케이션의
  40%가 특정 업무용 AI 에이전트를 통합할 것으로 전망했으며(2025년 5% 미만 대비 급증), 이는 기존에
  없던 "인터페이스 레이어"가 새로 필요해짐을 의미한다고 보도된다. Microsoft, Salesforce, IBM, AWS,
  Google, Cohere, Glean, Lyzr 등이 각자 엔터프라이즈 AI 에이전트 플랫폼을 출시했다는 보도도 있다.
  NN/g의 "State of UX 2026" 보고서는 신뢰(trust)가 AI 경험 설계의 핵심 과제라고 짚으며, 사용자가
  섣부른 AI 기능에 데인 경험이 있으면 신규 AI 기능 채택에 저항한다고 설명한다 — "점진적 위임
  (progressive delegation)"으로, 사용자의 승인 이력에 따라 자율성 범위를 단계적으로 넓히는 접근이
  이 문제에 대응하는 방식으로 소개된다. 다만 이는 업계 일반 동향 소개이며, LG전자의 "AI Agent
  전사 가이드 1.0"이 이런 투명성·오버라이드·점진적 위임 같은 요소를 구체적으로 포함하는지는 확인된
  사실이 아니다.
  (source: [Agent UX: UI Design for AI Agents in 2026 — Fuselab Creative](https://fuselabcreative.com/ui-design-for-ai-agents/),
  [Understanding Enterprise AI Agents: The 2026 Guide — Lyzr](https://www.lyzr.ai/blog/enterprise-ai/),
  [Enterprise AI Agents: The 2026 Strategy, Selection, and Deployment Guide — Neontri](https://neontri.com/blog/enterprise-ai-agents/))

- **"AI Agent 기회 영역"의 구체 내용** — 벤치마킹을 통해 어떤 갭/기회가 발굴됐는지(예: 실패 처리,
  멀티턴 대화, 권한 위임 UX 등) 구체적으로 제공되지 않았다.
- **"UX/GUI 가이드 1.0"의 실제 목차/범위** — 어떤 원칙·컴포넌트·인터랙션 패턴을 다루는지, 위에서
  언급한 업계 표준 요소(투명성, 오버라이드, 실패·정정 UX 등)가 포함되는지 확인되지 않았다.
- **"제품별 적용 협의"의 대상 제품과 현재 상태** — 어떤 제품 라인(가전, TV, 모바일 액세서리 등)과
  협의 중인지, 협의가 초기 단계인지 합의 임박 단계인지 불명확.
- **"주요 인터랙션 개선"의 구체 내용** — 어떤 인터랙션이, 어떤 방식으로 개선됐는지(또는 개선 예정
  인지) 구체적 항목이 제공되지 않았다.
- **시기** — 2026년 중 정확히 언제(상반기/하반기, 특정 분기) 각 단계가 진행/완료됐는지 명시되지
  않았다. 특히 가이드 1.0 배포 시점과 제품 적용 협의 시작 시점 간의 시차도 불명확.
- **"1.0"이라는 버전 표기의 함의** — 향후 2.0 등 개정 계획이 있는지(즉 지속적으로 갱신되는 리빙
  다큐먼트로 운영되는지) 확인되지 않았다.
- 외부에 공개된 정보가 아니므로, 2027 사업계획 외부 공유 자료에 이 내용을 포함할 경우 사내 보안/
  공개 범위 정책을 먼저 확인해야 한다.
